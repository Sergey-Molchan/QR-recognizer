# QR-recognizer
Программа для считывания QR-кодов с видео или картинки состоит на базе 
qreader - для считывания кодов и расшифровки
cv2 - для чтения изображений и конвертации цвета

Усложнение кода:
image = cv2.cvtColor(cv2.imread(image_path), cv2.COLOR_BGR2RGB) 
Перевод с BGR в RGB нужен для цветных QR-кодов то есть и цветных видео если считывание с фото
и полная уверенность что QR-коды будут черно белые то можно оставить 
image = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE) 
"Перевод с BGR в RGB нужен, потому что OpenCV читает изображения в формате BGR (синий-
зеленый-красный), а большинство других библиотек, включая QReader, ожидают RGB (красный-
зеленый-синий). Для цветных QR-кодов это обязательно, для черно-белых — опционально."
